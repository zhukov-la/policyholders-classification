# Классификация страхователей транспортных средств

Бинарная классификация клиентов страховой компании на табличных данных с помощью градиентного бустинга CatBoost.
Учебный проект в рамках соревнования Kaggle [«Классификация страхователей транспортных средств»](https://www.kaggle.com/competitions/findata-policyholders).

## Результат

| Метрика | Значение |
| --- | --- |
| ROC-AUC (публичный лидерборд) | **0.6727** |
| Место | **134 из 666** (топ-21%), с первой попытки |
| ROC-AUC лидера | 0.6849 |

## Задача и данные

- **Задача:** предсказать целевой класс страхователя (бинарная классификация).
- **Метрика:** ROC-AUC.
- **Данные:** 151 406 записей, 28 анонимизированных признаков (числовые, бинарные и категориальные), пропуски, дисбаланс классов.

## Подход

1. **EDA:** баланс классов, доля пропусков по признакам.
2. **Разбиение train / valid / test (70/15/15)** до любой обработки, со стратификацией по целевой переменной, чтобы избежать утечки данных.
3. **Предобработка:**
   - пропуски в категориальных признаках заменены отдельной категорией;
   - пропуски в бинарных признаках трактуются как 0;
   - пропуски в числовых признаках обрабатывает сам CatBoost.
4. **Модель:** `CatBoostClassifier` с нативной обработкой категориальных признаков, взвешиванием классов (`auto_class_weights='Balanced'`) и ранней остановкой по ROC-AUC на valid.
5. **Порог классификации** подбирается по F1 только на valid. Итоговые метрики считаются на отложенном test.
6. **Интерпретация:** анализ важности признаков.
7. **Сабмит:** финальная модель обучена на всех размеченных данных, в сабмит отправляются вероятности (метрика соревнования — ROC-AUC).

## Как запустить

1. Скачайте данные со [страницы соревнования](https://www.kaggle.com/competitions/findata-policyholders/data) и положите их в папку `data/`.
2. Установите зависимости и запустите ноутбук:

```bash
pip install -r requirements.txt
jupyter notebook policyholders_catboost.ipynb
```
